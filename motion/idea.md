- 피그마 파일: 수원문화재단 개선 (`vHdYOApUUHSwrm6FWCcFD4`)
- 확인 범위: `3-6. 모션` 페이지 → `모바일` 섹션 (9817:8785)
- 이 페이지에는 모바일 화면만 있음 (태블릿·데스크탑 화면 없음)
- 피그마는 보기만 했고 수정하지 않음
- 표기: **없음** = 필요한 화면·요소가 피그마에 없음 / **확인 필요** = 화면만 봐서는 판단하기 어려움

## 2. 따로 움직일 요소와 분리 여부

분리 여부 표기:
- **분리 불필요**: 이미 따로 된 레이어나 화면이라 그대로 움직일 수 있음
- **분리 필요**: 따로 움직이려면 레이어를 떼어 내야 함
- **확인 필요**: 부품(인스턴스) 안에 묶여 있어 바로 뗄 수 있는지 판단하기 어려움
