# 모션 디자인 기준

> 이 파일의 역할: 홍보 모션 영상의 화면 규격, 색, 글꼴, 배경, 사용 소스를 정한 디자인 기준표다.

- 색·글꼴 값의 출처는 Figma 파일 `vHdYOApUUHSwrm6FWCcFD4`의 변수와 스타일이다. 이 값을 옮겨 둔 `src/styles/tokens.css`를 기준으로 했다.
- 장면 구성과 사용할 화면을 고른 이유는 `motion/idea.md`를 따른다.

## 3. 글꼴

| 항목 | 값 |
|---|---|
| 글꼴 | Pretendard |
| 굵기 | 400 (Regular), 600 (SemiBold), 700 (Bold) |
| 줄 간격 | 150% |
| 영상 자막·카피용 글꼴 | [확인 필요] 화면과 같은 Pretendard 사용을 제안 |

### 글자 크기 (Figma 텍스트 스타일, 모바일 기준)

| 스타일 | 크기 (원본) | 굵기 | 쓰이는 곳 |
|---|---|---|---|
| heading/h1 | 24px | 700 | 완료 문구 "신청하신 사항이…" |
| heading/h2 | 22px | 700 | 모달 제목 [확인 필요] |
| heading/h3 | 19px | 700 | 소제목(신청자 정보), 달력 제목 |
| heading/h4 | 17px | 700 | 카드 제목 |
| body/m | 17px | 400 | 본문, 입력값 |
| body/s | 15px | 400 | 보조 본문 |
| body/s-bold | 15px | 700 | 보조 강조 |
| button/label | 17px | 700 | 버튼 글자 |
| form/label | 17px | 700 | 입력 칸 이름 |
| form/helper | 15px | 400 | 입력 규칙 안내 |
| form/error | 15px | 700 | 오류 문구 |

- 영상에서는 위 크기에 화면 배율(3배 제안)을 곱한다. [확인 필요]
- 영상 자막·카피 크기: [확인 필요]
